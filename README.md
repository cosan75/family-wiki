# 우리집 수첩 (가족 위키)

가족 일정 · 아이별 숙제/준비물 · 학교 공지/가정통신문 · 우리집 위키를 한 화면에서 보는 단일 HTML 앱.

## 참고한 글 (2026-11-13 크롤링)

- 출처: Threads @mixdesign 게시글 `DfmgBBVklM6` (조회 1.5만, 2026-11-12 게시)
- 요지: 예전에 만든 가족 대시보드(가족 일정·아이들 학업 진도·학원 숙제·학교 공지)에
  에이전트 3개를 붙여 **학습 진도·숙제·준비물을 자동으로 입력**하게 했고, 잊지 않을 "우리집 위키"를 만들었다.
- 댓글에서 나온 핵심: "가족 일정판은 만들어도 입력을 안 하면 방치된다 → 에이전트가 입력을 대신해 주는 게 핵심"
  (작성자도 첫 서비스는 같은 이유로 안 쓰게 됐다고 답함).
- 스크린샷 8장에서 확인한 화면 구성: 홈(달력+다가오는 일정+날씨+아이별 할 일·가정통신문 카드) /
  학원 주간 시간표(아이별 색) / 할 일(숙제·해야 할 일·루틴, "오늘까지" 배지) /
  학교생활(학교공지·가정통신문·급식) / 가족 일기 / 날씨.

이 앱은 위 구성을 참고해 **새로 설계**한 것이며, 원작의 이름·캐릭터·그림은 쓰지 않았다.

## 쓰는 법

`index.html`을 브라우저로 열면 끝. 데이터는 이 PC 브라우저의 localStorage(`family-wiki-v1`)에만 저장된다.

| 메뉴 | 내용 |
|---|---|
| 홈 | 이번 달 달력, 오늘·내일 일정, 아이별 오늘 할 일·미확인 통신문 |
| 일정 | 주간 보기(일회성 일정 + 매주 반복 학원), 일정/학원 추가 |
| 할 일 | 아이별 숙제·준비물·할 일·루틴(루틴은 매일 자동 초기화) |
| 학교생활 | 학교공지·가정통신문, 회신 마감 표시 |
| 위키 | 우리집 지식 페이지, `[[페이지 이름]]` 링크, 검색 |
| 자동 입력 | 알림장·문자·통신문을 붙여넣으면 날짜·준비물·숙제를 골라 후보로 만든다 |
| 설정 | 가족 구성원, JSON 내보내기/가져오기(덮어쓰기·합치기) |

## 사용법 카드뉴스

`cardnews.html`(정사각 9장, 화면에서 넘겨 보기) · `cardnews/card-01~09.png`(1080×1080, 스레드·인스타용).
한 장만 다시 뽑으려면 `cardnews.html?card=N`을 1080×1080으로 캡처한다.

## 에이전트로 자동 입력하기

원글처럼 에이전트가 입력을 대신하게 하려면, Claude에게 알림장/통신문 사진·텍스트를 주고
아래 형식의 JSON을 만들게 한 뒤 **설정 → 가져오기(합치기)** 로 넣으면 된다. `id`가 같으면 갱신, 없으면 추가.

```json
{
  "tasks":   [{ "member": "m3", "type": "숙제|할 일|준비물|루틴", "title": "수학 익힘 48~51쪽", "subject": "수학", "due": "2026-11-14" }],
  "events":  [{ "title": "공개수업", "date": "2026-11-15", "start": "10:30", "end": "11:20", "members": ["m3"], "place": "", "memo": "" }],
  "notices": [{ "member": "m4", "kind": "학교공지|가정통신문", "title": "현장체험학습 동의서", "date": "2026-11-13", "due": "2026-11-14", "body": "" }],
  "classes": [{ "member": "m3", "title": "수학학원", "days": [1,3,5], "start": "16:00", "end": "17:30", "place": "" }],
  "wiki":    [{ "title": "학원 정보", "category": "학원", "body": "## 수학학원\n- 월수금 16:00" }]
}
```

- `member` 값은 설정 화면의 구성원 id(m1~m4 등)를 쓴다. `days`는 0=일 … 6=토.
- 개인정보(실명·연락처)는 이 PC 밖으로 내보내지 않는 것을 기본으로 한다.
